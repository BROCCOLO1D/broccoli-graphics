# Hero style options

Temporary preview set for choosing the README hero style. Each option uses the user-provided animated source and keeps the same 17-frame timing at 720x450.

- `01-source-sharp.gif` — sharpened/source-forward, least stylized.
- `02-crisp-poster.gif` — quantized poster look with fewer dither artifacts.
- `03-neon-atkinson.gif` — neon palette with Atkinson diffusion.
- `04-bayer-comic.gif` — ordered Bayer/comic halftone style.
- `05-hi-contrast-fs.gif` — high-contrast monochrome Floyd–Steinberg style.
